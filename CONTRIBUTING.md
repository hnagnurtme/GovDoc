# Contributing to GovDoc Intellisense

Thank you for your interest in contributing to **GovDoc Intellisense**! We welcome contributions of all forms, including bug fixes, new features, documentation improvements, and feedback.

## Code of Conduct

By participating in this project, you agree to abide by our Code of Conduct:
- Be respectful, constructive, and inclusive.
- Focus on what is best for the community.
- Avoid personal attacks or harassing behavior.

## How to Contribute

### 1. Reporting Bugs
If you find a bug, please open an Issue with:
- A clear description of the problem.
- Step-by-step instructions to reproduce it.
- Expected behavior vs. actual behavior.
- Environment details (OS, Python version, Docker version).

### 2. Suggesting Features
We welcome ideas! To suggest a feature:
- Describe the feature you want and the problem it solves.
- Discuss potential implementations.

### 3. Submitting Pull Requests (PRs)
1. Fork the repository and create your branch from `master`:
   ```bash
   git checkout -b feature/your-awesome-feature
   ```
2. Write clean, documented code and keep comments up-to-date.
3. Verify your changes build and run locally using Docker or virtual environment.
4. Push your branch to GitHub and open a Pull Request targeting `master`.
5. Ensure your PR description clearly states what changes were made and why.
