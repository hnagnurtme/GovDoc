# Security Policy

## Supported Versions

Currently, security support is active for the following versions of GovDoc Intellisense:

| Version | Supported |
| :--- | :--- |
| **0.1.x** | :white_check_mark: Yes |
| **< 0.1.0** | :x: No |

## Reporting a Vulnerability

We take the security of GovDoc Intellisense seriously. If you discover any security vulnerability, please **do not** open a public issue. Instead, report it responsibly:

1. Send an email to the maintainers at `contact@hnagnurtme.dev` (or open a private security draft on GitHub).
2. Include a detailed description of the vulnerability, including step-by-step instructions to reproduce it (POC).
3. We will acknowledge receipt of your vulnerability report within 48 hours and work with you to patch the issue before making a public disclosure.
